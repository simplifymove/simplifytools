## SEARCH SUMMARY

To find a specific tool's custom content:
1. Search for `tool.id === 'SLUG'` in file
2. Find the opening `{` after the condition
3. Content continues until closing `})`
4. Most blocks are indented 8 spaces and wrapped in a `<div>` with class `max-w-6xl mx-auto px-4 md:px-8 py-16`
